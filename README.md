# Atoms Demo

> 一句话把想法变成可运行的单页应用。AI 生成、iframe 实时预览、对话迭代、版本自动存档。

## 这是什么

一个迷你版 Atoms：输入一句中文需求（比如"带分类和月度饼图的记账本"），调用大模型生成完整单文件 HTML，右侧 iframe 直接渲染，刷新不丢。

## 功能

- **输入即生成**：中文自然语言 → 完整可运行的单文件 HTML
- **生成过程可见**：中间对话区显示"理解需求 → 生成结构 → 完善样式"状态，右边预览区转圈
- **对话式迭代**：在现有应用基础上提修改意见（"把主色换成深蓝"）
- **赛马模式(可选)**：一次生成两个版本，并排预览，挑一个采用
- **版本存档与回切**：每次生成都记入历史，点任意版本切回去，后续修改基于它
- **最近应用入口**：刷新后 Hero 页直接看到之前做过的应用，点进去继续
- **一键导出**：把生成的 HTML 下载成本地文件
- **数据持久化**：所有应用存在浏览器 localStorage，刷新 / 重开浏览器都在
- **Mock 兜底**：没配 API Key 也能跑完整流程（内置 4 个示例模板：记账本、贪吃蛇、咖啡店落地页、房贷计算器）

## 技术选型

- **纯静态前端**：单个 `index.html` + `app.js`，无构建、无后端
- **模型**：DeepSeek Chat（OpenAI 兼容协议，国内直连，便宜）
- **样式**：Tailwind CDN
- **持久化**：localStorage

### 为什么是纯静态？

笔试 4 小时窗口里，部署稳定性 > 架构炫技。纯静态可以直接扔 Vercel / Netlify / GitHub Pages，零配置拿 https 链接，不会卡在服务器、端口、环境变量这些地方。模型 Key 存在用户浏览器 localStorage 里，不经过任何我方服务器，也没有泄露风险。

## 本地运行

```bash
cd atoms-demo
python3 -m http.server 8767
# 打开 http://localhost:8767
```

### 配置 API Key（可选）

点右上角"⚙ 设置"，填入 [DeepSeek](https://platform.deepseek.com/) 的 API Key（sk- 开头）。Key 只存在你自己浏览器里。
不配 Key 也能用，会走 Mock 模式——内置 4 个示例模板（记账本、贪吃蛇、咖啡店落地页、房贷计算器），按关键词匹配返回；匹配不到时给一个漂亮的演示说明页。

## 已知取舍

- **没做登录/多用户**：单用户本地工具，localStorage 足够。真要多用户得换云数据库，时间不够。
- **没做云端同步**：换浏览器数据没了。MVP 阶段 local-first 优先。
- **版本历史只保留 prompt + html 快照**：没做 diff / 时间线可视化。
- **赛马模式是简单并行两路**：没有自动打分择优，靠人眼看。
